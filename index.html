Rezultati:

🔐 Si funksionon “shift”-i në këtë aplikacion?

Ky projekt përdor algoritmin Vigenère Cipher, ku çdo shkronjë e mesazhit zhvendoset sipas një key. Key mund të jetë numër ose shkronjë.

🔢 Kur key është NUMËR

Nëse key është numër (p.sh. 1234), çdo shifër përdoret direkt si zhvendosje.

  • 1 → 1 hap
  • 2 → 2 hapa
  • 3 → 3 hapa

👉 Sa më i madh numri, aq më shumë “ec” shkronja në alfabet.

🔤 Kur key është SHKRONJË

Nëse key është fjalë (p.sh. CODE), çdo shkronjë kthehet në numër:

  • A = 0
  • B = 1
  • C = 2
  • D = 3
  • ...
  • Z = 25

👉 Shembull: CODE → C=2, O=14, D=3, E=4

⚙️ Si funksionon kriptimi

  • Enkriptimi: shtohet shift-i
  • Dekriptimi: zbritet shift-i

Formula: (shkronja + shift) mod 26

🎯 Përmbledhje

  • Numër → përdoret direkt si hap
  • Shkronjë → konvertohet në alfabet
  • Key vendos sa “ec” çdo shkronjë
